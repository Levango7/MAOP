# MAOP用户操作手册

## 1. 项目简介
MAOP（AI运维编排平台）是一款支持LLM智能路由、可视化工作流编排、成本优化的AI运维管理工具，帮助企业降低LLM使用成本，提升AI运维效率。

---

## 2. 快速启动
### 2.1 环境要求
- Python >= 3.9
- Node.js >= 18（前端依赖）
- 内存 >= 2GB

### 2.2 后端启动
```bash
# 安装依赖
pip install -r requirements.txt

# 初始化数据库（首次启动自动完成）
python py/maop/api/workflow_api.py
python py/maop/api/monitor_api.py
python py/maop/api/audit_api.py
```
服务默认运行在8080端口，可通过启动参数修改。

### 2.3 前端启动
```bash
cd frontend
npm install
npm run dev
```
前端默认运行在3000端口。

## 3. 核心功能操作指南
### 3.1 工作流编排
1. 登录系统后进入「可视化编排」页面
2. 点击工具栏按钮添加节点：支持触发节点、过滤节点、LLM节点、响应节点
3. 拖拽节点到画布，通过拖拽句柄连接节点，构建完整的工作流DAG
4. 配置每个节点的参数：
   - 触发节点：选择触发事件类型
   - 过滤节点：配置过滤条件表达式
   - LLM节点：输入要执行的提示词任务
   - 响应节点：配置响应动作（告警/自动修复/创建工单等）
5. 点击「导出YAML」生成工作流配置文件，可保存复用

### 3.2 LLM成本优化配置
1. 进入「成本管理」-「路由配置」页面
2. 配置三档模型降级链：
   - 高端推理模型：用于复杂分析、架构设计等任务
   - 中端模型：用于代码翻译、修改等中等难度任务
   - 低成本/免费模型：用于简单查询等低难度任务
3. 设置预算降级阈值：当剩余预算低于阈值时自动降级到低耗模型
4. 开启模型健康度自动探测，自动切换不可用模型

### 3.3 监控与审计
- 进入「监控大盘」页面可查看：
  - 模型调用成功率、延迟分布
  - 成本消耗趋势、预算剩余
  - 路由分布统计
- 进入「审计日志」页面可查询用户操作记录，支持按用户/操作类型/时间范围筛选，可导出CSV/JSON格式日志。

## 4. 接口文档
### 4.1 接口认证
所有接口需要在Header中携带API Key：
```
X-API-Key: 你的API Key
```

### 4.2 核心接口
#### 编译DAG为YAML
- 地址：POST /api/v1/workflow/compile
- 权限要求：workflow:create
- 请求示例：
```json
{
  "name": "告警处理工作流",
  "nodes": [
    {"id": "start", "type": "trigger", "config": {"event": "alert"}},
    {"id": "llm", "type": "llm_node", "config": {"task": "分析告警原因"}}
  ],
  "edges": [
    {"from": "start", "to": "llm"}
  ]
}
```

#### 查询工作流列表
- 地址：GET /api/v1/workflow/list
- 权限要求：workflow:view

#### 查询审计日志
- 地址：GET /api/v1/audit/logs?user_id=xxx&limit=100
- 权限要求：audit:view

## 5. 常见问题
### Q1：工作流编译失败，提示存在环？
A：检查是否有节点的输出连接回自身或上游节点，DAG必须是无环图，调整节点连接即可。

### Q2：API接口返回403无权限？
A：检查当前API Key绑定的用户角色是否有对应权限，或联系管理员分配权限。

### Q3：数据重启后丢失？
A：项目默认使用SQLite持久化存储，数据存储在maop.db文件中，不要删除该文件即可保留数据。
