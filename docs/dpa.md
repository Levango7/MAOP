# MAOP 数据处理协议（DPA）

> 生效日期：2026-08-11 ｜ 版本：v1.0 ｜ 文档维护：MAOP 团队
>
> 本 DPA 是 [服务条款](terms-of-service.md) 的附录，适用于 MAOP 企业版托管服务（SaaS）模式。

## 第 1 章 当事方

- **数据控制者**（以下简称"客户"）：签署企业版托管服务合同的法人。
- **数据处理者**（以下简称"MAOP 团队"）：MAOP 团队，作为托管服务的运营方。
- **适用法规**：PIPL、GDPR、CCPA 及其他适用数据保护法规。

## 第 2 章 定义

| 术语 | 定义 |
|------|------|
| 个人数据 | 可识别自然人的任何信息 |
| 处理 | 对个人数据执行的任何操作（收集、存储、使用、传输、删除等） |
| 数据主体 | 个人数据对应的自然人 |
| 标准合同条款 | 跨境数据传输的标准合同条款（SCC） |
| 子处理者 | MAOP 团队委托的第三方处理者 |
| 安全事件 | 导致个人数据意外或非法销毁、丢失、篡改、未授权披露或访问的事件 |

## 第 3 章 处理范围

### 3.1 处理目的

MAOP 团队仅按客户指令处理个人数据，目的限于：

1. 提供企业版托管服务功能（编排、记忆、模型路由）。
2. 维护服务可用性与性能（监控、告警）。
3. 履行法律义务（审计日志、合规报告）。
4. 按客户书面指令进行的数据迁移、备份恢复。

### 3.2 处理类别

| 类别 | 示例 | 数据主体 |
|------|------|----------|
| 账户数据 | 邮箱、姓名、角色 | 客户员工 |
| 认证数据 | SAML/OIDC/LDAP 断言 | 客户员工 |
| 编排数据 | Agent 配置、执行历史 | 客户员工 |
| 记忆数据 | 三层记忆内容 | 客户员工 |
| 使用指标 | API 调用统计 | 客户员工 |
| 审计日志 | 访问与操作记录 | 客户员工 |

### 3.3 处理期限

- 处理期限为客户合同存续期 + 合规要求的保留期（审计日志 7 年）。
- 合同终止后，MAOP 团队在 90 天内删除或返还全部个人数据（审计日志按合规要求保留）。

## 第 4 章 子处理者

### 4.1 现有子处理者

MAOP 团队使用以下子处理者，完整列表维护于 [隐私政策](privacy-policy.md) §3.3：

| 子处理者 | 处理内容 | 所在地 | DPA 状态 |
|----------|----------|--------|----------|
| 云基础设施商 | 计算/存储/网络 | 客户选定区域 | 已签署 DPA |
| 邮件服务商 | 通知邮件 | 全球 | 已签署 DPA |
| 监控服务商 | SLI 指标 | 全球 | 已签署 DPA |

### 4.2 子处理者变更

- MAOP 团队新增或替换子处理者前需提前 30 天书面通知客户。
- 客户可在 30 天内提出异议；若异议无法解决，客户可终止合同并要求返还数据。
- 所有子处理者均签署不低于本 DPA 保护标准的协议。

## 第 5 章 数据主体权利

### 5.1 协助义务

MAOP 团队协助客户响应数据主体行使以下权利：

- 知情权、访问权、更正权、删除权、限制处理权、可携带权、反对权。

### 5.2 响应流程

1. 数据主体向客户提出请求。
2. 客户判断是否需要 MAOP 团队协助（如数据导出、删除）。
3. 客户通过 `privacy@maop.io` 向 MAOP 团队提交协助请求。
4. MAOP 团队在 15 天内提供所需数据或执行操作。
5. 客户向数据主体反馈结果。

### 5.3 直接请求

若数据主体直接向 MAOP 团队提出请求，MAOP 团队将：

1. 不直接处理，转告数据主体向客户提出。
2. 通知客户有此类请求，由客户决定后续处理。

## 第 6 章 安全措施

### 6.1 技术措施

| 措施 | 实现 |
|------|------|
| 传输加密 | TLS 1.2+（`MAOP_TLS_MIN_VERSION=TLSv1_2`），弱版本默认拒绝 |
| 存储加密 | AES-256-GCM 静态加密 |
| 密钥管理 | HashiCorp Vault，支持自动轮换 |
| 访问控制 | RBAC + 多租户 RLS 隔离 |
| 审计 | 仅追加审计日志，不可篡改 |
| 网络隔离 | 服务间 mTLS，最小暴露面 |
| 漏洞管理 | 关键漏洞 24 小时内修复，依赖 [SECURITY.md](../SECURITY.md) |

### 6.2 组织措施

| 措施 | 实现 |
|------|------|
| 人员培训 | 全员年度数据保护培训 |
| 权限审批 | 最小权限原则，访问需审批 |
| 保密协议 | 全员签署保密协议 |
| 事件响应 | 24×7 安全值班，事件响应流程 |
| 数据销毁 | 离职人员权限即时撤销 |

## 第 7 章 安全事件响应

### 7.1 通知义务

- MAOP 团队在确认安全事件后 **72 小时内** 书面通知客户。
- 通知内容：事件性质、涉及数据类别与数量、已采取与拟采取的缓解措施、数据主体可能受影响的风险。
- 若事件可能对数据主体权利与自由造成高风险，MAOP 团队协助客户履行对监管机构与数据主体的通知义务。

### 7.2 协助义务

- MAOP 团队配合客户进行事件调查，提供相关日志与证据。
- MAOP 团队采取措施控制与消除事件影响。
- 事件结束后 30 天内提供事后分析报告（Postmortem）。

### 7.3 客户义务

- 客户在获知事件后按适用法规向监管机构与数据主体通知。
- 客户配合 MAOP 团队的事件调查，提供必要信息。

## 第 8 章 跨境数据传输

### 8.1 区域选择

客户在签约时选定数据存储区域：

| 区域 | 覆盖 | 合规 |
|------|------|------|
| 中国大陆 | 数据存储与处理在中国境内 | PIPL |
| 欧盟 | 数据存储与处理在欧盟境内 | GDPR |
| 美东 | 数据存储与处理在美国 | CCPA |

### 8.2 跨境传输

- 默认情况下，客户数据不跨区域传输。
- 若技术支持需跨区域访问（如 EU 客户需 US 工程师协助），须：
  1. 签署标准合同条款（SCC）。
  2. 客户书面同意。
  3. 访问全程审计。
- 中国大陆区域数据不向境外传输（PIPL 要求）。

## 第 9 章 数据返还与删除

### 9.1 合同终止时

- 客户在合同终止时可选：
  1. **数据返还**：MAOP 团队在 30 天内以标准格式（JSON）导出并提供下载链接。
  2. **数据删除**：MAOP 团队在 90 天内删除全部个人数据。
- 审计日志按合规要求保留 7 年，保留期内仅用于合规审计，不用于其他目的。

### 9.2 删除确认

- 数据删除完成后，MAOP 团队提供删除证明（含删除时间、范围、方式）。
- 备份数据在 30 天备份保留期内滚动删除，保留期内不可访问（仅用于灾难恢复）。

## 第 10 章 审计与合规

### 10.1 客户审计权

- 客户每 12 个月可对 MAOP 团队进行一次数据保护审计。
- 审计需提前 30 天书面通知，在工作时间进行，不影响服务运行。
- 审计范围限于与本 DPA 相关的处理活动、安全措施、文档记录。

### 10.2 MAOP 团队合规证明

MAOP 团队可提供以下合规证明（按合理请求）：

- SOC 2 Type II 报告（年度）。
- ISO 27001 认证（若持有）。
- 渗透测试报告（年度，摘要版）。
- 数据保护影响评估（DPIA）摘要。

## 第 11 章 责任与赔偿

- MAOP 团队因违反本 DPA 导致客户对数据主体承担赔偿的，MAOP 团队按其责任比例向客户赔偿。
- 赔偿上限为客户 12 个月内实际支付的服务费总额。
- 上述限制不适用于 MAOP 团队的故意或重大过失。

## 第 12 章 修订

- 本 DPA 修订提前 30 天通知客户。
- 因法规变更导致的必要修订，可缩短通知期（不少于 7 天）。
- 客户对修订有异议可终止合同并要求返还数据。
