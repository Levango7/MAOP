# MAOP 隐私政策

> 生效日期：2026-08-11 ｜ 版本：v1.0 ｜ 文档维护：MAOP 团队

## 第 1 章 引言

MAOP（Multi-Agent Orchestration Platform）尊重并保护用户隐私。本隐私政策说明 MAOP 在个人版（自托管、MIT 许可）与企业版（托管服务）两种模式下如何收集、使用、存储和保护个人信息。

### 1.1 控制者与处理者

| 模式 | 法律角色 | 责任 |
|------|----------|------|
| 个人版自托管 | 用户为数据控制者 | MAOP 团队不接触任何用户数据 |
| 企业版自托管 | 客户为数据控制者，MAOP 为软件提供方 | 数据处理完全在客户基础设施内 |
| 企业版托管（SaaS） | 客户为数据控制者，MAOP 团队为数据处理者 | 受 [DPA](dpa.md) 约束 |

### 1.2 适用法规

本政策遵循以下法规要求：

- 中华人民共和国《个人信息保护法》（PIPL）
- 《数据安全法》
- 欧盟《通用数据保护条例》（GDPR）
- 美国《加州消费者隐私法》（CCPA）

## 第 2 章 收集的信息

### 2.1 个人版自托管

个人版**不收集、不上传**任何信息至 MAOP 团队服务器。所有数据存储在用户本地文件系统：

- `data/maop.db`（SQLite）：编排状态、记忆、配置。
- `data/.api-key`（可选）：API key 加密密钥。
- `logs/`：运行日志。

> **遥测说明**：MAOP 默认**不**启用任何遥测或"phone home"机制。`MAOP_OTEL_ENABLED=0` 为默认值，仅当用户显式配置 OpenTelemetry exporter 时才会上传指标，且目标地址由用户完全控制。

### 2.2 企业版自托管

企业版同样**不向 MAOP 团队上传任何业务数据**。许可证校验（参见 `py/maop/enterprise/license.py`）仅向客户配置的 License Server 发送机器指纹（CPU ID、MAC 地址哈希），不含业务数据。

### 2.3 企业版托管（SaaS）

托管服务模式下，MAOP 团队作为数据处理者，按 [DPA](dpa.md) 处理客户数据。收集的信息类别：

| 类别 | 内容 | 用途 | 法律依据 |
|------|------|------|----------|
| 账户信息 | 邮箱、姓名、租户 ID、角色 | 身份识别、访问控制 | 合同履行 |
| 认证信息 | SAML/OIDC/LDAP 断言、JWT | 单点登录、会话管理 | 合同履行 |
| 编排数据 | Agent 配置、执行历史、Plan-Execute-Verify 记录 | 服务提供 | 合同履行 |
| 记忆数据 | 三层记忆（短期/长期/向量）内容 | 服务提供 | 合同履行 |
| 使用指标 | API 调用次数、延迟、错误率 | SLA 监控、容量规划 | 合法利益 |
| 安全日志 | 审计日志、访问日志 | 安全审计、合规 | 合法利益 |
| 财务信息 | 开票信息、支付凭证 | 计费 | 合同履行、法律义务 |

### 2.4 不收集的信息

MAOP **不**收集以下信息：

- LLM 提示词与补全的明文内容（托管模式下由客户配置的 LLM 提供商直接处理，MAOP 仅转发）。
- 客户基础设施的 SSH 密钥、K8s kubeconfig 等凭证（仅存储经 Vault 加密的引用）。
- 浏览器指纹、跨站点追踪 cookie。
- 用户的地理位置精确信息（仅保留 IP 所在国家/地区用于合规）。

## 第 3 章 数据使用

### 3.1 使用目的

收集的信息仅用于：

1. **提供服务**：编排执行、记忆管理、模型路由等核心功能。
2. **账户管理**：身份认证、权限控制、租户隔离。
3. **服务运营**：监控、告警、故障诊断、容量规划。
4. **安全合规**：审计日志、入侵检测、合规报告。
5. **计费结算**：用量统计、发票开具。

### 3.2 使用限制

- MAOP **不**将客户数据用于：
  - 训练机器学习模型（包括 LLM、推荐模型）。
  - 销售或共享给第三方（除 §3.3 列明的处理者）。
  - 营销分析或用户画像。
- 客户数据与 MAOP 自身运营数据（如 SLI 指标）严格隔离，运营数据不可逆向识别个人。

### 3.3 第三方处理者

托管模式下，MAOP 使用以下第三方处理者（均签署 DPA，数据仅限欧盟/美国/中国区域）：

| 处理者 | 用途 | 数据 | DPA 状态 |
|--------|------|------|----------|
| 云基础设施商 | 计算、存储、网络 | 全部托管数据 | 已签署 |
| LLM 提供商（OpenAI/Anthropic） | 模型推理 | 客户显式配置后转发的提示词 | 客户与提供商直接签约 |
| 邮件服务商 | 通知、告警邮件 | 邮箱地址、邮件内容 | 已签署 |
| 监控服务商 | Status 页、告警 | SLI 指标（不含业务数据） | 已签署 |

## 第 4 章 数据存储与安全

### 4.1 存储位置

| 模式 | 存储位置 | 加密 |
|------|----------|------|
| 个人版 | 用户本地文件系统 | SQLite 透明加密（可选） |
| 企业版自托管 | 客户基础设施 | 客户自行决定 |
| 企业版托管 | 客户选定区域（中国大陆/欧盟/美东） | 传输 TLS 1.2+；存储 AES-256 |

### 4.2 数据保留

| 数据类别 | 保留期 | 删除方式 |
|----------|--------|----------|
| 账户信息 | 账户存续期 + 30 天 | 账户注销后自动删除 |
| 编排历史 | 配置的保留期（默认 90 天） | 滚动删除 |
| 三层记忆 | 配置的保留期（`MAOP_MEMORY_PRUNE_TTL_DAYS`，默认 90 天） | 滚动删除 |
| 审计日志 | 7 年（合规要求） | 到期自动删除 |
| 安全日志 | 1 年 | 到期自动删除 |
| 备份 | 30 天 | 到期自动删除 |

### 4.3 安全措施

- **传输加密**：所有 API 强制 TLS 1.2+（参见 `MAOP_TLS_MIN_VERSION=TLSv1_2`）。
- **存储加密**：托管模式数据静态加密 AES-256-GCM。
- **密钥管理**：HashiCorp Vault 管理加密密钥，支持自动轮换。
- **访问控制**：RBAC + 多租户隔离（RLS），最小权限原则。
- **审计**：所有管理操作记录审计日志，不可篡改（仅追加）。
- **漏洞管理**：依赖 [SECURITY.md](../SECURITY.md) 的漏洞披露流程，关键漏洞 24 小时内修复。

## 第 5 章 数据主体权利

### 5.1 GDPR/PIPL 权利

数据主体（仅托管模式下的终端用户）享有以下权利：

| 权利 | 说明 | 响应时限 |
|------|------|----------|
| 知情权 | 了解哪些数据被处理 | 30 天 |
| 访问权 | 获取自身数据副本 | 30 天 |
| 更正权 | 修正不准确的数据 | 15 天 |
| 删除权 | 要求删除个人数据 | 30 天 |
| 限制处理权 | 限制处理范围 | 30 天 |
| 可携带权 | 以结构化格式导出数据 | 30 天 |
| 反对权 | 反对特定处理 | 30 天 |

### 5.2 行使权利

- **托管模式**：通过 `privacy@maop.io` 提交申请，需提供身份验证信息。
- **自托管模式**：数据主体应向其组织的数据保护联系人申请，MAOP 团队不直接处理。

### 5.3 数据可携性实现

```bash
# 导出指定租户的全部数据（企业版）
maop admin export --tenant <tenant-id> --output tenant-export.json

# 导出格式：JSON，含编排历史、记忆、配置
```

## 第 6 章 Cookie 与本地存储

### 6.1 Cookie

MAOP 仪表盘使用以下 Cookie，均为"严格必要"类别，无需同意横幅：

| Cookie | 用途 | 保留期 | 是否第三方 |
|--------|------|--------|-----------|
| `maop_session` | JWT 会话令牌 | 会话结束 | 否 |
| `maop_edition` | Edition 偏好（personal/enterprise） | 365 天 | 否 |
| `maop_locale` | 语言偏好 | 365 天 | 否 |

### 6.2 本地存储

仪表盘使用浏览器 `localStorage` 存储 UI 偏好（主题、侧边栏状态），不含个人身份信息。

## 第 7 章 儿童隐私

MAOP 面向企业与开发者，**不**面向 16 岁以下儿童。MAOP 不 knowingly 收集儿童个人信息。若发现误收集，将立即删除。

## 第 8 章 政策变更

- 本政策变更将在 [docs/privacy-policy.md](privacy-policy.md) 更新并发布通知。
- 重大变更（如新增数据处理目的）提前 30 天通知。
- 历史版本归档于 `docs/archive/privacy/`。
