## 背景：钥匙现状（不存在"没有钥匙"的阻塞）

- **企业生产签名私钥**：``F:/Keys/maos/maop_enterprise_prod.pem``（Ed25519，
  含 2026-10-01 备份）——本会话即持钥会话，MAOS 清单重签（32 模块）一直
  用它。**私钥保管呈批的是它的" Marketplace 目录签名"角色分配**，不是
  要不要给我钥匙。
- **Marketplace 目录验签公钥**：M0 接线读 ``MAOP_MARKETPLACE_VERIFY_KEY``
  （路径或内联公钥）；当前无生产目录签名方，验签门在未配置时为
  fail-open（``require_signature=False`` 默认，见决策 D4）。

---

## D1 目录签名私钥的角色分配（谁签 marketplace 目录）

**推荐：复用 `maop_enterprise_prod.pem`（同一把生产私钥，角色=企业发布
签名根），M0 阶段由持钥会话签发目录；MAOS 侧后续增加专用
`marketplace_dir_signing.pem` 子钥（派生签名链）作为 V2。**

理由：
- M0 验签实现只认"单公钥直验"（``PackageVerifier``），专用子钥要动验签
  面（信任链/多公钥），属功能扩展不是治理问题——先让链路真跑起来；
- 复用生产钥的爆炸半径可控：marketplace 目录是**产品分发面**，与企业
  模块清单签名同属"发布物完整性"职责，同一签发主体（企业发布流程）
  在治理上自洽；
- 反对意见已考虑：单钥双用途意味着一把钥泄露同时波及模块清单与
  marketplace——故 V2 派生子钥列为本文件既有方向，不新增呈批项。

## D2 验签公钥分发通道（消费者从哪拿公钥）

**推荐：三通道并行，按优先级回退——① 企业安装包内置（wheel/deb 的
`config/marketplace_verify_key.pub`，随产品走）② 环境变量
``MAOP_MARKETPLACE_VERIFY_KEY`` 指路径或内联（运维覆盖/换钥窗口）③
企业 distribution server 的 HTTPS 端点拉取（M1 扩展，M0 不实现）。**

理由：
- 内置通道零网络依赖、离线环境可用（MAOS 企业部署的现实约束）；
- env 覆盖是 M0 已落地的配置面，语义（本地覆盖优先）与轮换演练兼容；
- HTTPS 拉取引入"bootstrap 信任"问题（拉公钥的通道本身要验）——
  M1 再议，避免 M0 范围膨胀。

## D3 轮换与吊销 SLA（钥匙泄露/例行轮换怎么办）

**推荐口径（待批数值）**：
- **例行轮换**：12 个月一次，随企业半年度发布窗口执行（不单独发版）；
- **紧急吊销**：私钥疑似泄露 → 24 小时内发新目录（新钥签名）+ 发布
  patch 版本更新内置公钥；受影响目录条目全部重签；
- **吊销生效面**：旧公钥在消费者侧只通过"升级内置公钥"失效——
  env 覆盖的部署由运维按企业通告自行换钥（写入 runbook）；
- 双钥过渡窗口：换钥后旧签名目录 **7 天**宽限期（同时配置新旧两把
  验签钥即可，M0 的 ``PackageVerifier`` 单钥限制 → 宽限期由"先验新钥、
  失败再验旧钥"的 try 顺序实现，属 M1 小扩展）。

理由：数值与仓库既有"发布节奏规范"（patch 每周 1 个上限）兼容；
24h 紧急口径对齐常见密钥泄露响应基线；7 天宽限避免一键换钥打爆
存量消费者。

## D4 ``require_signature`` 默认值演进（什么时候默认强制验签）

**推荐：三步演进，当前停在第 1 步——**
1. **现在（M0 已交付）**：默认 ``False``（fail-open 但告警可见）；
   ``--require-signature`` 显式开启；生产部署按企业决策配置。
2. **触发条件 → 默认 ``True``**：当且仅当 ① 生产目录已有签名方（D1
   批准 + 首个签名目录发布）② 内置公钥通道（D2①）随产品分发 ③
   存量安装完成一次带钥升级。三者齐备后一个 minor 版本切默认。
3. **终态**：未配置验签钥 + ``require_signature`` 未显式关闭 → 安装
   路径打 **warn + 安装计数埋点**（观测面），为将来 fail-close 收集
   数据；显式关闭保留（企业内网自建目录场景）。

理由：fail-closed 切换的时机由事实（签名方存在 + 公钥可达）触发而非
拍脑袋；观测面让"谁在裸奔安装"可见，切默认不盲切。
