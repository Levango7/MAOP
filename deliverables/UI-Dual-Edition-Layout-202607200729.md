# MAOP 双路线 UI 排版设计

| 字段 | 值 |
|------|-----|
| 版本 | 1.0 |
| 日期 | 2026-07-20 |
| 关联 | PRD-Dual-Edition-Architecture-202607200729 |

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 共享 API 层 | 两个版本调用同一套 REST API，数据格式一致 |
| 个人版精简 | 只保留个人开发者需要的页面，去掉 RBAC/租户/审计 |
| 企业版增强 | 在共享页面基础上增加管理类页面 |
| 视觉统一 | 同一套配色/图标/间距体系，仅布局密度不同 |
| 暗色主题 | 两个版本默认暗色 (#0f172a 背景) |
